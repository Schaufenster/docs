Die KB ist **eine git-basierte Quelle** (`Schaufenster/docs` → documentation.ai). Sie wird von zwei Arten von Consumern gelesen
und durch einige reviewte Inflows gespeist.

## Wer sie liest

## Was Claude füttert

Claude wird durch **vier** Quellen geerdet, jede für einen anderen Zweck:

| Quelle | Wofür sie da ist |
| --- | --- |
| **KB MCP (documentation.ai)** | Stabiles, offizielles Wissen (diese KB) |
| **egora-data MCP** | Live-Geschäftsdaten (Bestellungen, Anfragen, KPIs) — siehe [egora data](/integrations/egora-mcp) |
| **Notion** | Arbeitsdokumente, live gelesen — siehe [Notion](/integrations/notion) |
| **Skills** | Power-User-Verhalten in Claude Code / Cowork |

Faustregel: **KB MCP** für "Wie funktioniert X", **egora-data** für "Wie sind die aktuellen Zahlen",
**Notion** für "Was ist der neueste Entwurf".
